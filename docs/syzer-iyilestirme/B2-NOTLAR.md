# B2 Notları

## Kapsam dışı bırakılanlar

- Orkestra aynı dalga içindeki ortak dosya yazma çakışmalarını tespit etme/serileştirme: B2 kapsamı dışında bırakıldı; Yasin tarafından ayrı kartta ele alınmalı.
- `run_command` yoluyla çalışma alanı dışına yazma koruması: yalnızca `FILE_WRITE` akışının mevcut B1 koruması korunmuştur; kabuk komutu analizi/engellemesi B2 kapsamında uygulanmadı. Yasin için ayrı güvenlik kartı gerekir.
